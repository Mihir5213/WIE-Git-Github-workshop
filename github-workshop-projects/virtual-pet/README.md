# Virtual Pet Challenge 🐾

Welcome to the Virtual Pet challenge! This project is a digital pet that needs your care to stay happy and healthy. Your mission is to bring it to life by implementing the core logic in JavaScript.



## The Challenge 🎯

Your task is to complete the missing JavaScript functions and fix the HTML in `main.js` and `index.html`. The pet has three primary stats that you must manage: **Hunger**, **Happiness**, and **Cleanliness**.

## How to Contribute 🚀

This project is an incomplete challenge. All the detailed instructions for completing the main objectives are located in the **`CONTRIBUTING.md`** file.

Please read **[CONTRIBUTING.md](./CONTRIBUTING.md)** first to understand which functions need to be implemented and how they should work.

## 💎 Hidden Bonus Challenge
There’s a secret Easter egg hidden in the project files for sharp-eyed contributors. If you explore the code carefully, you’ll find a subtle comment hinting at a special feature to enhance the pet's environment. The challenge is to discover this hint and implement the feature using HTML, CSS, and JavaScript. Contributors who discover and complete this hidden feature earn **bonus points** for their curiosity and creativity.
