# Neon Snake Game Challenge 🐍

A modern, web-based version of the classic Snake game. Your mission is to implement the core game logic to make it playable, using HTML5 Canvas and vanilla JavaScript.



## The Challenge 🎯

Your task is to complete the `main.js` file. The game board is set up, but the snake doesn't move, there's no food, and it can't die. You need to implement the functions that control the snake's movement, food generation, and collision detection.

## How to Contribute 🚀

This is an incomplete challenge. All detailed instructions for completing the main objectives are in the **`CONTRIBUTING.md`** file.

Please read **[CONTRIBUTING.md](./CONTRIBUTING.md)** first to understand which functions you need to implement.

## 💎 Hidden Bonus Challenge
A true snake master can handle any speed. For those who explore the code, a hidden comment suggests a bonus feature: adding speed controls to the game. Implementing functional buttons to make the snake faster or slower will test your understanding of the game loop and earn you **bonus points**.
