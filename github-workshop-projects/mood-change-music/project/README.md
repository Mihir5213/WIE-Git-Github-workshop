# 🎨 Mood Board Workshop

A fun interactive JavaScript mini-project for the Git & GitHub Workshop!  
Participants will learn how to contribute to open-source projects by completing missing code and improving functionality.

---

## 🌟 Project Overview
The Mood Board app changes the background, emoji, and music based on the selected mood.  
It’s a beginner-friendly project that teaches DOM manipulation, event handling, and Git collaboration.

---

## ✨ Features
- Interactive mood buttons (Happy, Calm, Energetic)
- Dynamic background changes
- Emoji and text display for mood
- Background music based on selection
- Expandable for new moods (e.g., Relaxed, Focused)

---

## 🧠 Demo
When a user clicks a mood:
- The background color changes
- The emoji appears
- A suggestion text displays
- A short audio clip plays
